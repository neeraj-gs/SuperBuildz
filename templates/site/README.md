# Site

Generated by Super Builds. A Next.js site with a 3D hero, a motion system, and
a CRM at `/admin`.

## The idea

_Written by the build in stage 1._

## Running it

```sh
npm install
npm run dev
```

The CRM is at `/admin`. The login was shown once in Super Builds when the site
was built; it is stored hashed in `.env.local`.

## Putting it online

Press Publish in Super Builds, or:

```sh
npx vercel login
npx vercel --prod
```

Every value in `.env.local` must also exist in the Vercel project's
Environment Variables. The CRM needs `DATABASE_URL` (Postgres — Neon or
Supabase) on Vercel; locally it uses `data/site.db`.
